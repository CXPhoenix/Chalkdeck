# Wangxing core conflict example

## 忘形流核心衝突

張忘形風格的 `wangxing.text_visual_relation` 與「拿掉觀點／視覺關係，圖片只當無關裝飾」
衝突：圖文不再共同表達同一觀點或明確關係，圖片也不再幫助理解。保留核心的建議是
使既有視覺與觀點具有可說明的對應；這只是尚未接受的建議，不列為已套用偏好。

交付原本核心：精簡觀點與視覺共同傳達同一觀點或明確關係，視覺幫助理解而非僅裝飾。
保留必要限定；若供自行閱讀，觀點、圖文關係與限定不得依賴講者補充。
這是來源啟發的專案綜整，不是官方英文命名或固定圖文數量公式，亦不改寫／製作素材。

```yaml
style_id: wangxing
core_rules:
  - rule_id: wangxing.text_visual_relation
    constraint: >-
      精簡觀點文字與視覺共同傳達同一觀點或明確關係；視覺幫助理解而非僅裝飾。
      保留理解素材所需的條件與限定；若供自行閱讀，觀點、圖文關係與必要限定
      須在沒有講者補充時仍可理解。
adjustable_rules: []
```
