# Jobs Markdown/YAML handoff example

This illustrates the existing contract; wording is not an exact-output template.

## 賈伯斯流核心指引

`jobs.single_focus` 要求展示、效益、揭露或比較元素共同支持一個明確陳述的焦點；
精簡文字與相關視覺證據支持這個焦點，而不是各自形成競爭的主要主張。
多個物件可以服務同一比較。保留正確理解焦點所需的條件與限定，不能為了
精簡而省略。這是來源啟發的專案綜整，不是 Jobs 的原話、固定物件數或全局敘事公式。
內容改寫與簡報製作由其他工具處理。

```yaml
style_id: jobs
core_rules:
  - rule_id: jobs.single_focus
    constraint: >-
      讓展示、效益、揭露或比較元素支持一個明確陳述的焦點；
      文字與視覺元素須支持該焦點，而非形成各自競爭的主要主張。
      多個物件可服務同一比較；保留正確理解焦點所需的條件與限定。
adjustable_rules: []
```
