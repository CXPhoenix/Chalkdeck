# Jobs core conflict example

## 賈伯斯流核心衝突

要求「電池續航、企業招聘、午餐選單三個互不相關的主張皆為同等主要焦點」，
違反 `jobs.single_focus`：沒有一個明確共同焦點，文字與視覺變成競爭的主要主張。
保留核心的建議是採用一個明確展示／效益／揭露／比較焦點，讓其他元素支援它；
此建議尚未接受，不列入已套用偏好，也不改寫或重組素材。

交付原本核心：展示、效益、揭露或比較元素支援一個明確焦點，文字與視覺支援
該焦點而不互相競爭；多個物件可支援同一比較，必要限定仍保留。
此關係是來源啟發的專案綜整，不是 Jobs 的官方方法或固定物件數公式。

```yaml
style_id: jobs
core_rules:
  - rule_id: jobs.single_focus
    constraint: >-
      展示、效益、揭露或比較元素支援一個明確陳述的焦點；文字與視覺服務焦點，
      不成為互相競爭的主要主張。多個物件可共同服務一項比較，保留正確理解素材
      所需的條件與限定。
adjustable_rules: []
```
