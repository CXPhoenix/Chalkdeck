# Gates core conflict example

## 比爾蓋茲流核心衝突

要求「拿掉必要指標、單位、共同測試假設、限定，只保留 120／90 作裝飾」，違反
`gates.evidence_relation`：數字與比較重點脫離，且解讀所需條件被移除。保留核心
的建議是以清楚層級保留比較標籤及條件；這只是尚未接受的建議，不列入已套用偏好。

原本核心仍是證據、數量或系統元件連到明確比較／系統重點，保留必要標籤、單位、
假設及限定。本例是 A 平均回應時間 120 ms、B 90 ms，相同硬體及工作負載，僅適用此次
測試條件。這是專案綜整，不是 Gates 官方公式；只提供風格約束，不計算或重組。

```yaml
style_id: gates
core_rules:
  - rule_id: gates.evidence_relation
    constraint: >-
      證據、數量或系統元件連到明確比較或系統重點；若標籤、單位、假設與限定
      對解讀必要，須保留。將 A 平均回應時間 120 ms 與 B 90 ms 連到兩方案比較，
      保留平均回應時間指標、ms 單位、相同硬體及工作負載、僅適用此次測試條件的限定。
adjustable_rules: []
```
