# Jobs adjustment rule record

ID: `jobs.presentation_preferences`. Classification: adjustable. Evidence class:
project synthesis / user-selected preference, not creator quotation or official menu.
Basis: accepted non-core/core boundary and the [core/source record](core-rule.md).
J1 illustrates several related objects; J3 informs benefit focus. Neither establishes
mandatory colors, counts or a universal layout. Reuse their edited-excerpt/press-release
reading limits; no full keynote or rendered-slide measurement added.

Apply only to requested compatible appearance or supporting-element preferences.
State accepted changes and applicable conditions in both Markdown and constraint.
Display, benefit, reveal or comparison elements support one stated focal point;
text/visual elements support it rather than independent competing primary claims.
Preserve necessary interpretation qualifications. With no applicable preference,
this optional record is absent; no default color or object count is invented.

Compatible example: a colored background and four products serve one battery-life
comparison with test-specific limits retained. Four is case-specific, not a threshold.
Conflicting example: unrelated battery, recruitment and lunch claims receive equal
primary status without a shared point. Color cannot repair that lost relationship.
These judgments concern style guidance, not rewriting or producing a slide.
