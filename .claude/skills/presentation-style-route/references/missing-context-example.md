# Missing context examples

A generic request to select a presentation style has no anchor. Ask, for example:

請提供這份素材要達成的用途，或希望觀眾如何理解重點；有了其中一項，就能選擇一個主要風格。

“The audience is teachers” alone also has no purpose/expression anchor. Ask in English:

What is the presentation meant to accomplish, or what expression needs should it support?

Do not infer expertise, humor, venue or a default style from “teachers.” These
clarifications have no settings profile yet. The current caller's language controls
the real response; examples do not override it.
