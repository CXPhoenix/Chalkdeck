# English guidance example

This style refers to 張忘形; wangxing is a project identifier, not an official English name. wangxing.text_visual_relation connects concise viewpoint text to a meaningful task/person visual relation that helps understanding. Keep the claim limited to this team. For independent reading, the viewpoint, visual relation and qualifications must be understandable without a speaker. Color and no humor are compatible preferences.

The accepted preferences use `wangxing.presentation_preferences`.

These rules are source-led project synthesis, not creator quotations or official numerical formulas. Style constraints only; no content transformation.

```yaml
style_id: wangxing
core_rules:
- rule_id: wangxing.text_visual_relation
  constraint: Concise viewpoint text and visuals communicate the same viewpoint or an explicit relation; the visual contributes to understanding rather than decoration. The task/person mapping supports clear responsibilities reducing duplicate work in this team. For independent reading, the viewpoint, visual relationship and necessary qualifications must be understandable without a speaker.
adjustable_rules:
- rule_id: wangxing.presentation_preferences
  constraint: Accept color and no humor while keeping the meaningful task/person relationship and the qualification in this team. For independent reading, necessary information must not depend on speaker supplementation.
```
